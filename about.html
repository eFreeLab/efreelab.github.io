关于轩扫描

一个把「写过的卷子变回空白卷」做扎实的小工具

为什么要做这个

家里有小学生就会发现：试卷做错一次，想重做就得再找一份空白卷。 要么满世界找电子版，要么手抄题目，要么拿橡皮擦得纸都起毛。

轩扫描想解决的就这一件事：拍一张写过的卷子，去掉笔迹，还原成能重新打印的空白卷。 顺手把扫描、去阴影、导出 PDF 这些周边也做好。

技术方案

部分做法说明
相机CameraXAndroidX 官方库，Apache-2.0
界面Jetpack Compose + Material3六主题 × 深浅色自研设计语言
透视校正自研投影变换 + 双线性采样不引入 OpenCV，包体积小
黑白化自动色阶 + 大津法纯 Kotlin，无第三方依赖
PDF 导出android.graphics.pdf.PdfDocument系统 API，零依赖
官网 / 消息GitHub Pages + Jekyll静态站，零后端、零数据库
协议红线：所有第三方组件必须是 Apache-2.0 / MIT / BSD 这类宽松协议。 不使用 GPL / LGPL / AGPL 组件，避免商业版被迫开源。 例如 PDF 导出用的是系统 API 而不是 AGPL 的 iText，DOCX 导出也是手写 OOXML。

内测版 vs 商业版

邪修内测版（当前）商业版（规划中）
功能完整完整 + 学校/机构功能
费用免费收费
分发官网 + 网盘应用商店
安装提示有「未知来源」提示无
数据保障内部版本，不保证兼容正式迁移与保障

隐私承诺

  • 照片全部本地处理，不上传服务器
  • 不要求注册账号，不收集通讯录、定位、短信
  • 官网无 Cookie、无统计脚本、无广告
  • 唯一的联网行为是「检查更新」时读取一个静态 JSON 文件
