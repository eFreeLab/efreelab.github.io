使用教程

按功能分节，哪一节不会就点哪一节

一、拍照扫描

  1. 打开轩扫描，首页点「拍照扫描」。
  2. 把试卷平铺，四角尽量放进屏幕上的取景框，尽量填满画面——拍得越满，出来的字越清晰。
  3. 光线暗的点右上角闪光灯图标；注意别让自己的影子挡住纸面。
  4. 点快门拍照。也可以点左下角图标从相册导入已经拍好的照片。

调整边框

拍完会进入「调整边框」页。App 会先自动识别纸张四角； 不准的话直接用手指拖四个圆点贴到纸的四个角上，框外会自动压暗。

识别不准怎么办：纸和桌面颜色太接近、地面反光、纸没拍全时容易识别失败， 这时会提示「没找到清晰边缘」——手动拖四角即可，一样准。

选扫描档位

档位适合什么
高清黑白最常用。纯文字试卷、练习题，字迹最清晰、文件最小
灰度要保留一点层次，比如铅笔画的图
增强有图表、照片的页面，自动拉平光照
原图不想做任何处理，只做透视校正

二、擦掉手写笔迹

在结果页点「擦除笔迹」。轩扫描会用四层策略处理：

  1. 颜色分离：先把红笔、蓝笔这类明显不同于印刷黑字的颜色挑出来。
  2. 形态区分：印刷字每个同字形状几乎一样，手写却因人而异——按形状聚类把两者分开。
  3. 空白卷差分：如果你手上有一张没写过的同版卷子，扫进来当模板， 两图对齐后直接把差异部分用模板像素填掉，效果最好。
  4. 人工兜底：关键位置会被提示让你确认；擦错了的地方可以手动补写回来。
学生党用法：卷子已经写完了才想起来要擦？ 借同学一张没写过的同版卷子扫一下当模板，效果远好于纯自动擦除。

三、导出与分享

  • 保存 PNG：结果页点「保存到相册」，图片会存到系统相册的「轩扫描」文件夹。
  • 分享：点「分享」直接发给微信 / QQ，不会往公共存储里塞垃圾文件。
  • 导出 PDF：多页扫描后在文件页选「合并为 PDF」，按页码顺序排好即可打印。

四、错题本

擦除前 App 会自动留一份原图存档，做错的题可以一键收进错题本。 期末复习时在错题本里勾选需要的题，直接拼成一份新卷子导出打印。

五、换主题 / 深色模式

「设置」里有六套配色：爱马仕橙、西柚色、茶绿、马当、海雾、乔迪蓝， 每套都配了对应的深色方案。深色模式可以选「跟随系统 / 强制浅色 / 强制深色」。

六、检查更新

「设置 → 检查更新」会读取本站的 version.json， 有新版本时给出版本号和更新说明，并跳转到下载页。 整个检查过程只读取一个静态 JSON 文件，不上传任何设备信息。
