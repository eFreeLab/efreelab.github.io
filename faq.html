常见问题

提问前先翻翻，八成问题这里都有

安装时提示「风险应用」「发现病毒」，是真的中毒了吗？

不是。这是 Android 对所有「非应用商店来源 APK」的统一提示，跟你从哪儿下的、软件干什么的无关。

只要你是在本网站的蓝奏云或GitHub Releases下载的，就可以放心继续安装。

轩扫描在开发时刻意规避了几类最容易引发误报的做法：不使用第三方加固壳、不动态加载 DEX/SO、不申请通讯录/定位/短信等无关权限。这些都是手机管家判定风险的高权重特征。

想自己验证：装完后用手机管家扫一遍，或把 APK 传到 VirusTotal 看看。

我的照片会被上传到服务器吗？

不会。扫描、透视校正、黑白处理、笔迹擦除、OCR 全部在手机本地完成。

App 唯一的网络请求是「检查更新」时读取本站的一个静态 JSON 文件，这个请求里不包含任何照片、账号或设备标识。

不联网能用吗？

能。拍照、扫描、擦除、导出这些核心功能完全离线可用。

只有「检查更新」「AI 解题」这类功能需要联网。AI 解题是可选的，不配置也能正常使用其他所有功能。

为什么要相机权限？不给行不行？

不给就没法拍照扫描，App 的核心功能用不了。

轩扫描一共只申请 3 个权限：相机（拍照）、读取相册（导入已有照片）、网络（检查更新）。 没有通讯录、定位、短信、通话记录，也没有「读取已安装应用列表」这类容易被误会的权限。

边缘自动识别不准怎么办？

直接手动拖四个角就好，一样准，而且所见即所得。

识别失败的常见原因：纸张和桌面颜色太接近、地面/桌面有强反光、纸没拍全、背景太杂乱。 换一个对比度高的背景（比如深色桌面拍白纸）成功率会高很多。

手写笔迹擦不干净 / 把印刷字也擦掉了，怎么办？

两种情况都有兜底：

① 擦不干净：多半是笔迹颜色和印刷字太接近。改用「空白卷模板差分」——借同学一张没写过的同版卷子扫进来当模板，效果会好非常多。

② 擦错了：被误擦的地方可以手动补写回来，App 在关键位置也会先提示你确认。

内测版和商业版有什么区别？会不会突然收费？

内测版用于开发测试，功能完整、当前免费，但数据是内部版本，不保证向后兼容。

商业版会有正式的数据迁移与保障、上架应用商店（不再有风险提示）、以及后续的企业/学校功能。

如果未来内测版需要停止免费，App 内会提前给出通知并引导升级，不会静默停用。

支持 iOS / 鸿蒙吗？

目前只有 Android。

HarmonyOS 4 及以下一般可以直接安装 Android APK；纯血鸿蒙（HarmonyOS NEXT）暂不支持。 iOS 需要开发者账号（年费 688 元），在内测阶段暂不投入，等商业版再说。

扫描件存在哪里？会占手机空间吗？

存在 App 私有目录里，卸载 App 会一起清掉；主动「保存到相册」的会留在系统相册的「轩扫描」文件夹，卸载后仍在。

一页 A4 高清黑白扫描件大约 200 KB – 1 MB，比原照片小很多。

遇到 Bug / 想提建议，怎么反馈？

App 内「设置 → 反馈」可以一键生成回执码并复制反馈内容，粘贴到 GitHub Issues 或发给开发者都行。

带着回执码的反馈，开发者回复后你可以在 App 的 消息中心 里直接看到针对性回复。

为什么不用应用商店下载？

内测阶段走应用商店需要软著、备案、开发者账号等一整套手续，成本和时间都不划算。

先用官网 + 网盘分发，等商业版再上架。这也是为什么安装时会有「未知来源」提示。
